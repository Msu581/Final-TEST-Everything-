Comparison rule
Exact string match after whitespace normalisation. Case differences, punctuation variants (en-dash vs hyphen), and 7.6 vs 7.60 are all reported as mismatches, each with a note on the kind of difference. ABC ID rule: if neither copy carries an ABC ID the check is SKIPPED; if only one copy carries it, that is a mismatch.

Each sheet is recomputed from its own printed rows. Percentage = round(Total Marks / Maximum Marks × 100, 1) and SGPA = round(Total Credit Points / Total Credits, 1), both half-up (so 8.25 → 8.3). Supporting integrity checks (row credit points, column totals, maximum marks, grand total credit points) are also re-derived. Produces 2_sgpa_percentage_check.xlsx.

A student is WITHHELD when any subject's Grace cell contains the letter W or w. Column positions are never hard-coded — the header row is found by its repeated Grace/Result labels, and each subject band is bounded by the merged subject-name cell above it. A numeric grace mark (4, 2.5, 0) is never a W. The rule is deliberately literal. Produces 3_withheld_students.xlsx.

In the special OJT layout the OJT band header carries no code, and each student's own OJT role and code sit in the unlabelled column next to Program — e.g. Optometry Assistant (HAP423). That is read per student and joined to the band title, giving HAP423 / On the Job Training - 1 (Optometry Assistant). Sheet 2 of the report exports every Grace cell exactly as it appears, with its Excel row number.

From the PDFs: a candidate fails if any course row has grade F / FF / FAIL / AB / ABS / ABSENT / I / RA / R / NC / U, a grade point of 0, or absent marks (P is a pass; W is withheld, not failed). From the TR: any subject Result = F, Letter Grade = F, or overall Remark = F. Sheet 3 cross-checks the two lists and flags anyone found by only one source. Produces 4_failed_candidates.xlsx.
